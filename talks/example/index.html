Welcome

This is an example of the slide post format. Each slide has text on one side and an animation on the other.

On mobile, they stack vertically. On desktop, they appear side-by-side.

Concepts

Use slides to explain complex ideas with visual aids:

  • Break down information into digestible pieces
  • Pair explanations with animations
  • Create a smooth, scrollable experience

Custom Animations

Each slide can have its own custom animation defined with CSS or SVG.

You can create:

  • SVG animations (SMIL or CSS)
  • CSS keyframe animations
  • Canvas animations with JavaScript

Responsive Design

The layout automatically adapts:

  • Mobile: Stacked vertically, text above animation
  • Desktop: Side-by-side, 50/50 split

Animations trigger as you scroll into view using Intersection Observer.
